# compress-skill

## 作用
对已有 skill 进行压缩重构，收敛职责、移除冗余、外置资料，保留最小可执行协议。

## 适用场景
压缩已有 skill · 优化 SKILL.md 体积与结构 · 提高触发准确率 · 判断是否应拆分

## 不适用场景
生成业务代码 · 编写技术文档 · 实现插件逻辑

## 执行步骤

### 1. 识别单一职责
一句话概括："该 skill 仅用于……"。无法表述时说明过宽，需拆分。

### 2. 收窄触发边界
改写 description：用于[任务]。当[场景]时触发；不要用于[相邻任务]。
禁止：空泛能力词、"各种""综合处理"等模糊描述。

### 3. 删背景，保协议
正文仅保留：作用、适用/不适用、输入、步骤、输出、约束。
删除：背景介绍、原理解释、历史上下文、重复提醒。

### 4. 精简结构
- 同类示例保留一个代表案例
- 散文改为清单条目
- 长示例、模板、参考说明移至 references/

### 5. 验证最小化
最终应满足：直接理解何时使用 → 加载后直接执行 → 不易误触发相邻任务

## 输出
1. 压缩结论（是否保留/拆分）
2. 问题列表（冗余点、删除/外置建议）
3. 压缩后版本
4. 精简说明

## 约束
- 不删关键约束
- 不为短而模糊触发边界
- 不留"万能型"职责
- 背景材料不入正文
- 不用空话替代触发条件
